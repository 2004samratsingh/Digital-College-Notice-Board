# Digital College Notice Board

A responsive web application built using HTML5, CSS3, and JavaScript designed to digitalize college notices, announcements, and exam schedules. It utilizes browser localStorage to persist published notices seamlessly without requiring a separate database setup.

## Features

- **Publish Notices:** Easily input notice titles and descriptions via an interactive form.
- **Dynamic Display:** Automatically renders new announcements instantly at the top of the feed.
- **Persistent Storage:** Uses `localStorage` so that published notices remain saved even after refreshing or closing the browser.
- **Clean UI:** Styled with a modern layout, structured card components, and smooth responsiveness.

## Tech Stack

- **HTML5** (Structure & Forms)
- **CSS3** (Styling, Flexbox & Cards)
- **Vanilla JavaScript (ES6)** (DOM Manipulation & LocalStorage Handling)
